Práctica 4 – Turtle

Este programa lee un archivo llamado dibujante.txt y ejecuta las instrucciones que tenga adentro usando la librería turtle de Python.

Si encuentra una instrucción inválida, muestra un warning y sigue con la siguiente.

Archivos:

practica4_archivo_instruccionesG.py → el programa principal

dibujante.txt → las instrucciones de dibujo

Ejemplo de dibujante.txt:

dibujar_cuadrado(-200, 200, 100, "#ff69b4")
dibujar_triangulo(100, 200, 120, "#ffb6c1")
dibujar_circulo(0, -50, 60, "#ffc0cb")
dibujar_linea(-300, -200, 300, -200, "#db7093")


Cómo usar:
En la terminal escribe:
python practica4_archivo_instruccionesG.py
